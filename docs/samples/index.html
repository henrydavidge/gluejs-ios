Try GlueJS in a minute

Ready-made shortcuts that use GlueJS's Run JavaScript action. No Mac needed.

  1. Install GlueJS on your iPhone.
  2. On the iPhone, tap a sample below and choose Download. Open it from Safari's downloads (the arrow in the address bar) or from Files › Downloads.
  3. Tap Add Shortcut, then run it in the Shortcuts app and allow GlueJS when asked.
  4. Open GlueJS to see the run in the Runs tab: its input, output and timing.

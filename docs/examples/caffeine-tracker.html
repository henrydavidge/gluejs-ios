Caffeine Tracker & Sleep Cutoff Widget for iPhone

A personal iPhone shortcut that GlueJS makes possible: no app to install beyond GlueJS, built by your AI in a few minutes from one sentence.

What to ask for

“When I log a coffee, tell me when I'll be under 50 mg so I can sleep, and keep it on a widget.”

What you get

☕ 210 mg
Sleep-friendly after 10:40 PM · 318 mg today

How it works

  1. WhenAction button
  2. Shortcuts gets“latte”Ask for input
  3. GlueJSLog it, work out what's left5-hour half-life
  4. ThenWidget + notificationRefreshes every 30 min
Steps
GlueJS knows typical caffeine per drink, keeps two days in its Store, and recalculates on the widget every 30 minutes without logging anything new.
Connects to
Nothing. It works offline.
Keys & cost
None.

Build it

On a Mac with an AI coding agent such as Claude Code or ChatGPT's Codex, say:

“Use GlueJS (gluejs.sireniallc.com) to make me a shortcut: When I log a coffee, tell me when I'll be under 50 mg so I can sleep, and keep it on a widget.”

Or start from this example and change it:

npx gluejs-ios@latest new my-caffeine-tracker --from caffeine-cutoff
npx gluejs-ios@latest build my-caffeine-tracker

Open the .shortcut file it makes, tap Add Shortcut on your iPhone, and run it once. The full source is on GitHub, and llms.txt has everything your AI needs.

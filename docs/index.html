Code where Shortcuts gets clumsy

Shortcuts is great at triggers and device data. It's painful at loops, JSON, math and APIs. GlueJS handles exactly that part, and nothing else.

Shortcuts brings the data

Health, Calendar, Location, the share sheet, other apps' actions. Shortcuts handles those permissions. GlueJS only asks for Local Network access when a script needs it.

Real JavaScript, fast

Web APIs and your home

fetch any HTTPS API, or devices on your home network like Home Assistant.

Keys that stay put

Widgets

A run log that explains failures

How it works

  1. Tell your coding agent (Claude Code, or ChatGPT’s Codex) what you want: “a button that logs my workout and a widget with my streak.”
  2. It writes a small script and the shortcut around it, tests it on your Mac, and builds a signed shortcut file.
  3. Open the file and tap Add Shortcut. It syncs to your iPhone.
  4. Run it once, then automate it in Shortcuts.

What you need

  • An iPhone with iOS 18 or later and GlueJS.
  • A Mac (macOS 12 or later, signed into iCloud) with an AI coding agent that can run commands on it: Claude Code (Claude) or Codex (ChatGPT). The agent installs the gluejs-ios tools from npm.
  • For the Apple Intelligence examples: an iPhone that supports it, with iOS 26 or later.

Questions

Can Apple Shortcuts run JavaScript?

Only on web pages, on its own: Shortcuts' built-in Run JavaScript on Web Page action needs a Safari page from the share sheet. GlueJS adds a Run JavaScript action that works anywhere in a shortcut, on any input, with fetch for web APIs, saved values between runs and Home Screen widgets.

Can ChatGPT or Claude make an Apple Shortcut for me?

Yes. An AI coding agent on your Mac, such as Claude Code or ChatGPT's Codex, writes the script and the shortcut together with GlueJS's free gluejs-ios tools and builds a signed file you add with one tap. Just ask it to use GlueJS and point it at gluejs.sireniallc.com. A chat assistant can give you the files and commands to paste instead.

Do I need to know how to code?

No. You describe what you want in a sentence and your AI writes the code. Every line stays visible in the Shortcuts editor and in GlueJS's run log, so you can always see what runs.

How do I make a custom Home Screen widget with Shortcuts?

With GlueJS, a script publishes a number or a short list as a widget. Add the GlueJS widget to your Home Screen and choose it. Widgets can refresh themselves on a schedule, so a countdown, forecast or streak stays current.

Can a shortcut use my Health data, calendar or location with GlueJS?

Yes. Shortcuts reads Health, Calendar, Weather and Location and asks your permission for each kind of data, then passes only what that shortcut uses to GlueJS. GlueJS itself requests no device permissions.

Does GlueJS see or upload my data?

No. GlueJS has no account, no server, no analytics and no ads, and nothing is sent to us. A script only contacts the web services it was written to use, and API keys are sent only to the sites you allow.

Is GlueJS free?

Yes. You get 3 runs a day from Shortcuts and widgets, and the in-app Playground is always free. GlueJS Unlimited gives you unlimited runs and widgets that refresh all day for $4.99 a year.

What do I need?

An iPhone with iOS 18 or later and the GlueJS app. To have an AI build shortcuts for you: a Mac with Claude Code or ChatGPT's Codex, or any chat assistant that can give you the files and commands to paste.

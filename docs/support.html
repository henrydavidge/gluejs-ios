Installing a shortcut

Open the .shortcut file on your Mac (it syncs to your iPhone through iCloud) or AirDrop it to your iPhone, then tap Add Shortcut. Run it once by hand before you use it in an automation, so you can answer the one-time prompts.

"Allow … to run actions from GlueJS?"

Shortcuts asks this once for each new shortcut that uses GlueJS. Tap Allow.

"This action is trying to share … Health items, which is not allowed."

By default, Shortcuts limits how much Health data it passes to other apps. Either ask for fewer days of data, or turn on Settings → Apps → Shortcuts → Advanced → Allow Sharing Large Amounts of Data.

"No Samples Found"

Either there's no Health data of that kind yet, or Shortcuts wasn't given access to it. iOS only asks once; to turn access on later, open the Health app, tap your profile picture, then Apps › Shortcuts, and turn on the data the shortcut needs.

"You've used today's 3 free runs."

The free plan includes 3 runs a day from Shortcuts and widget refreshes, reset at midnight. GlueJS Unlimited removes the limit. The Playground in the app doesn't count.

Saving an API key

Run the "Set Up …" shortcut your agent made, check the sites listed in the confirmation and tap Set, then delete the setup shortcut. You can also add or edit keys in the app's Secrets tab.

"Secret … can't be sent to …"

The script tried to send a key to a site you didn't allow. If that site is correct, edit the key's allowed hosts in the Secrets tab. Keys only go over plain http:// to hosts you listed as http://name.

"No script named … in iCloud Drive › GlueJS › Scripts"

Shortcuts that use the Run Script File action read the script from iCloud Drive. Make sure iCloud Drive is on for your iPhone and your Mac (same Apple Account), open GlueJS once on your iPhone so it creates its folder, and push the script again from your Mac. The Data tab lists the script files your iPhone can see.

A widget isn't updating

Widgets without a refresh interval only change when their shortcut runs again. Refreshing widgets update about as often as iOS allows, which can be less often than requested. The Data tab shows each widget's last update and any refresh error.

Restoring or cancelling a subscription

Tap Unlimited in the Runs tab, then Restore Purchases. To cancel, go to Settings → your name → Subscriptions.

A script failed

Open the Runs tab and tap the run: it shows the input, output, console messages and the line that failed. Share that with whoever wrote the script, or with your coding agent.
